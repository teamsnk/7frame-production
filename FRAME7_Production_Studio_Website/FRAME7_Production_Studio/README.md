# FRAME 7 Production Studio — Static Website

A responsive, static production-studio landing page with seven switchable color themes:
1. Blue
2. Light
3. Dark
4. White
5. Green
6. Purple
7. Yellow

## Run locally
Open `index.html` in a modern browser. No build tools or package installation are required.

## Deploy to GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Select the deployment source/branch and root folder as prompted, then save.
5. Wait for GitHub Pages to publish the site.

## Before publishing
- Replace the temporary studio name if needed.
- Replace the demo email `hello@frame7studio.example` with a real address.
- Add real phone number, social links and completed portfolio items.
- The stock photographs are loaded from Unsplash and therefore require an internet connection.
- Portfolio examples are placeholders, not claims of completed client work.
- The site is a front-end demo. Contact form, booking, payments and backend are not included.

## Theme behavior
The theme dropdown switches the color palette instantly. The selected theme is saved in local browser storage when supported.

## Files
- `index.html` — page structure and content
- `style.css` — layout, responsive styles and seven themes
- `app.js` — theme selector, mobile navigation and active section highlighting
