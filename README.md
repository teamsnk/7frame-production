# Anjona Fabrics — Static Website ZIP

A responsive, single-page storefront demo for Anjona Fabrics.

## Run locally
Open `index.html` in a modern browser. Internet access is needed for Google Fonts and the remote demo images.

## Publish
Upload `index.html` to the root of a GitHub Pages repository, or deploy this folder as a static site to Cloudflare Pages.

## Important demo limitations
- Product listings, prices and images are sample content.
- Cart and demo orders are saved only in the current browser using localStorage.
- Admin preview code is `ANJONA-DEMO`; it is not secure authentication.
- The chat assistant uses local scripted replies, not a connected AI model.
- Newsletter signup does not send emails.
- Connect a secure backend, real inventory/order storage, a payment or WhatsApp checkout, and proper authentication before taking real orders.
