# FRAME 7 Premium Production Studio Website

A polished, responsive, static studio website with premium typography, cinematic imagery, subtle reveal transitions, interactive project filters, mobile navigation, and seven selectable themes.

## Included files
- `index.html` — full page structure and content
- `style.css` — responsive layout, visual design, all seven themes and reduced-motion support
- `app.js` — theme persistence, mobile menu, portfolio filters, reveal animations and active navigation

## Run
Extract the ZIP and open `index.html` in a modern browser. No build system or package installation is required.

## Publish on GitHub Pages
1. Create a repository on GitHub.
2. Upload the three website files to the repository root.
3. Go to **Settings → Pages**.
4. Choose the branch and root folder as the source, then save.
5. Open the Pages URL after deployment completes.

## Before going live
- Replace `FRAME 7` if your studio name changes.
- Replace `hello@frame7studio.example` with a real contact email.
- Add real contact/social links and your own portfolio work.
- The portfolio entries are concept placeholders, not claims of completed client work.
- Photos and Google Fonts load from external services and need an internet connection.
- This is a front-end static site; no database, server-side contact form, account system, or booking backend is included.
- Partnership, asset ownership, client permissions and revenue rules should be agreed in writing by all partners.
